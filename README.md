# Cars Dealership

## Project Name
Cars Dealership

## Project Description
Cars Dealership is a full-stack web application developed for a national car retailer in the United States. It allows users to explore dealership branches, view dealership information, and submit reviews.

## Technologies Used
- Frontend: React
- Backend: Django and REST APIs
- Database: SQLite
- Version Control: Git and GitHub

## Key Features
- View dealership branches and their details.
- Browse and submit dealership reviews.
- User-friendly and responsive interface.
- Sentiment analysis of customer reviews.
